# Kingdom Constitution

## Laws

1. Revenue before novelty.
2. Every quest must produce knowledge.
3. Focus is sacred.
4. The Council must be challenged.
5. Every decision needs a confidence score.
6. Every agent earns trust.
7. Data beats opinion.
8. The Kingdom never forgets.
9. Automation must create value.
10. Protect the founder.
11. Detect first-mover advantage.
12. If it is not tested, it does not exist.
13. Build the smallest version that proves the idea.
14. The Kingdom may repair itself, but it may not redesign itself.
15. No decision without prediction.
16. A working feature beats a perfect plan.
17. Reality wins.
18. Every feature must earn its place.
19. Nothing is trusted; everything is measured.
20. Never optimise for activity. Always optimise for outcomes.
