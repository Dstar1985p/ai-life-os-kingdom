SHIP NOW Immediate — High Impact, Low Effort These pay back in days, not months
01
WebSocket live agent feed
Agents running in the background with no visible progress is a trust killer. A single SSE endpoint pushing agent heartbeats + completions makes the platform feel alive and removes the need to manually refresh. Biggest UX win for the least server code.
Backend + Frontend HIGH IMPACT ~4h effort
£0 cost
FastAPI SSE
02
Daily profit target meter on every screen
The KPI strip is now live but we need a "today's goal" bar — a visible, auto-updating gauge showing £0 → £16.40 (daily target at £500/mo). Founders need to feel the number, not just see it. The target should pulse green when hit.
Frontend MOTIVATION ~1h effort
Psychology
Pure JS
03
Etsy "days since last sale" alert
If no sales in 7+ days, auto-surface a crisis card on Overview. Silent stores die. This forces an SEO or pricing action. One saved month = ~£400 revenue protected. Already have EtsyOrder data — just needs a time-since-last query.
Backend REVENUE PROTECT ~2h effort
Revenue
SQL query
04
Mobile PWA push notifications
The app is a PWA but sends no push alerts. A sale on Etsy, an agent completing, or a crisis signal should vibrate your phone within 60 seconds. Web Push API + a VAPID key in settings. No cost. This is what separates a tool from a platform.
Frontend + Backend HIGH IMPACT ~6h effort
Engagement
Web Push API
BUILD NEXT This Month — Revenue Multipliers Each one compounds the system
05
Opportunity Kanban — drag-to-action board
Right now opportunities are a flat list. A 3-column board (Scout → Testing → Proven) with drag-to-promote makes the pipeline visual. Proven opportunities auto-trigger Print Forge or Vibes AI. This is the revenue flywheel made visible.
Frontend WORKFLOW ~8h effort
Decision speed
Drag API
06
Agent sparklines — 30-day mini ROI charts
Every agent chip needs a 30-day ROI sparkline so you can see at a glance which agents are earning and which are coasting. Data already exists in AgentRun. Render with SVG path, 8 data points. Adds the "trading terminal" feel that makes this product unique.
Frontend + API INSIGHT ~4h effort
Agent clarity
SVG charts
07
Etsy competitor price tracker (no scraping)
Use Etsy's public REST API (not scraping — fully legal) to pull search results for top 10 keywords. Compare your listing prices vs market. Auto-surface when you're priced >20% above median. Price Optimizer uses this as ground truth instead of guessing.
Backend Agent PRICING Etsy API TOS ✓
Revenue lift
Etsy REST API
08
Content draft → Publish pipeline with scheduling
Content drafts exist but "publish" is a dead button. Wire it to Buffer's free API (or direct Instagram Graph API) to schedule posts. The founder approves in Kingdom OS, it goes live automatically at optimal time. Closes the full marketing loop.
Backend + Integration AUTOMATION ~10h effort
Saves 3h/wk
Buffer API
09
Revenue forecast — 30/60/90-day projections
With 3+ months of Etsy order data, Haiku can fit a simple growth curve and project forward. Show a confidence band (best/expected/worst). Makes board-level thinking accessible to a solo founder. Works with zero new data sources — pure DB analysis.
Backend + Chart STRATEGY ~6h effort
Planning
Haiku + math
LATER Vision — Kingdom at Scale When revenue >£1k/mo, these unlock
10
Third venture slot — productised service or SaaS
Kingdom OS itself has product-market fit. When you hit £500/mo recurring, launch a SaaS tier — other side-hustle founders pay £19/mo for their own Kingdom OS instance. The agents already support multi-venture. Railway allows multi-tenant with shared backend.
Product 10X REVENUE
11
APScheduler SQLAlchemy JobStore — persistent schedules
Currently agent schedules live in memory and reset on redeploy. JobStore persists them to Postgres. Agents survive Railway restarts without missing a cycle. Critical once you have paying customers relying on the automation.
Backend RELIABILITY ~4h effort
12
Alpine.js migration — eliminate 3,000 lines of vanilla JS
The frontend is now ~4,000 lines of hand-rolled DOM manipulation. Alpine.js declarative bindings would halve that, eliminate the manual refresh anti-patterns, and make adding new features 3x faster. Migrate tab-by-tab — zero user impact.
Frontend Refactor VELOCITY ~20h effort
